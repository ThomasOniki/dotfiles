== Requirements
- zsh
- zsh-fast-syntax-highlighting (this isn't a default package on linux, clone https://github.com/zdharma-continuum/fast-syntax-highlighting[repo] or use zsh-syntax-highlighting)
- zsh-autocomplete
- zsh-autosuggestions
- lsd
- trash-cli (on macos, /usr/bin/trash comes builtin)
- zoxide

== Notes
If you are not on an apple silicon mac using homebrew, you may need to change paths in .zshrc and .zprofile.
You should also remove the environement variables and aliases for things you don't use.
For example, this line in zprofile is only useful for homebrew rustup users.
[source,sh]
----
PATH="$HOMEBREW_PREFIX/opt/rustup/bin:$PATH"
----
